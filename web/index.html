Five forecasters, one honest walk-forward test

Each year is forecast by models trained only on earlier years, with a one-day embargo. 2012–2015 are development years; 2016–2019 were the pre-registered one-shot test, so v2 numbers there are labelled post hoc.

Weights can sum past 1: every member is too timid in storms (shrunk toward the average), and the stacker, fit only on earlier years, learned to stretch them. That stretch improves out-of-sample R² in every year tested.
Optuna's TPE sampler searches gradient-boosting hyperparameters on a time split inside each training window, starting from the pre-registered setting.

A forecast is only useful if you know when to trust it

Two checks: do the 90% intervals really contain 90% of outcomes, including when volatility jumps? And when the model says it is unsure, is it?

Adaptive conformal inference widens the interval after every miss and narrows it after every hit. Outcomes are fed back only once they are known (30 minutes later).

How it works

One pipeline, built so that nothing can see the future: every feature is computed from bars that closed before the decision, every model is trained only on earlier years, and every interval is updated only with outcomes that are already known.

Data3.1M one-minute ES futures bars (2010–2019), prior-day VIX, FOMC calendar. Point-in-time truncation tests on every feature.
25 featuresHAR volatility components, time-of-day profile, VIX, ranges, returns, volume, calendar, plus two pure-noise columns as a sanity check.
StormNetDilated temporal convolutions → Transformer self-attention over 240 one-minute bars, fused with the features. Heads: heteroscedastic volatility, non-crossing range quantiles, direction. 3-seed deep ensemble on Apple-silicon GPU.
EnsembleHAR + gradient boosting (Optuna-tuned in each window, exact TreeSHAP) + StormNet, stacked with non-negative weights fit on earlier years' out-of-sample forecasts.
Trust layerAdaptive conformal intervals with delayed feedback; aleatoric + epistemic uncertainty; 3-state hidden Markov regimes (filtered, never smoothed).

What makes it honest

  • Walk-forward by calendar year, expanding window, one-day embargo.
  • Pre-registered original study: hypotheses and the 2016–2019 test fixed before any model was fit, run once from a frozen git tag. v2 is labelled post hoc.
  • Tuning inside the window: Optuna never sees the test year.
  • Leak tests: features rebuilt from truncated data must match; a planted look-ahead must fail.
  • Noise features rank last in importance, as they should.

The one-sentence result

On identical inputs, machine learning explains about 80% of the variation in the size of the next 30-minute move, and essentially none of its direction.

That is the efficient-market hypothesis, measured: predictable price changes get traded away, but nothing arbitrages away volatility clustering. ML's value here is risk: sizing, stops, and knowing when the weather is turning.
